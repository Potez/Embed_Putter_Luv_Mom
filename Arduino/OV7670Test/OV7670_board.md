เขียนโค้ดไว้ที่ Arduino/OV7670Test/OV7670Test.ino แล้ว แต่ยังไม่ได้คอมไพล์ เพราะในเครื่องไม่มี arduino-cli ให้คอมไพล์และอัปโหลดผ่าน Arduino IDE เอง

การต่อสาย (OV7670 แบบไม่มี FIFO มี 18 ขา)

┌────────────┬───────────────────────────────────┐
│   OV7670   │               ESP32               │
├────────────┼───────────────────────────────────┤
│ 3V3        │ 3V3 (ห้ามต่อ 5V กล้องจะพัง)           │
├────────────┼───────────────────────────────────┤
│ GND        │ GND                               │
├────────────┼───────────────────────────────────┤
│ SIOD (SDA) │ GPIO 21 + ตัวต้านทาน 4.7kΩ ต่อขึ้น 3V3 │
├────────────┼───────────────────────────────────┤
│ SIOC (SCL) │ GPIO 22 + ตัวต้านทาน 4.7kΩ ต่อขึ้น 3V3 │
├────────────┼───────────────────────────────────┤
│ XCLK       │ GPIO 32                           │
├────────────┼───────────────────────────────────┤
│ PCLK       │ GPIO 33                           │
├────────────┼───────────────────────────────────┤
│ VSYNC      │ GPIO 34                           │
├────────────┼───────────────────────────────────┤
│ HREF       │ GPIO 35                           │
├────────────┼───────────────────────────────────┤
│ D0         │ GPIO 36 (VP)                      │
├────────────┼───────────────────────────────────┤
│ D1         │ GPIO 39 (VN)                      │
├────────────┼───────────────────────────────────┤
│ D2         │ GPIO 18                           │
├────────────┼───────────────────────────────────┤
│ D3         │ GPIO 19                           │
├────────────┼───────────────────────────────────┤
│ D4         │ GPIO 23                           │
├────────────┼───────────────────────────────────┤
│ D5         │ GPIO 25                           │
├────────────┼───────────────────────────────────┤
│ D6         │ GPIO 26                           │
├────────────┼───────────────────────────────────┤
│ D7         │ GPIO 27                           │
├────────────┼───────────────────────────────────┤
│ RESET      │ 3V3                               │
├────────────┼───────────────────────────────────┤
│ PWDN       │ GND                               │

- ขาที่เลี่ยง: ไม่ได้ใช้ GPIO 0, 2, 5, 12, 15 เพราะเป็นขา strapping ถ้าต่ออะไรไว้ตอนเปิดเครื่อง บอร์ดอาจบูตไม่ขึ้น
- ความยาวสาย: ใช้สายสั้น ไม่เกิน 10 ซม. ยิ่งสาย XCLK กับ PCLK ยาว ภาพจะเพี้ยนหรือมีสัญญาณรบกวน
- ตัวต้านทาน pull-up: ถ้าโมดูลกล้องไม่มีตัวต้านทานในตัว ต้องใส่ 4.7kΩ ที่ SIOD/SIOC เอง ถ้าไม่ใส่ จะขึ้น Camera init failed
